# Bug report template

This packaged copy follows `.github/ISSUE_TEMPLATE/bug-report.yml` in `radius-project/ai-extensions`. Prefer the live template when available. Use the `bug` label.

## Issue body

### Summary

A short description of the bug. Required.

### Area

Choose one: Radius plugin or skills; Radius canvas extension; Core packages (core, adapter-shared, adapter-canvas); Build, CI, or tooling; Documentation; Not sure.

### Steps to reproduce

The exact steps needed to reproduce the behavior. Required.

### Expected behavior

What did you expect to happen?

### Actual behavior

What actually happened? Include the sanitized error message. Required.

### Logs, screenshots, or stack traces

Include only reviewed, sanitized output in a fenced code block. Do not upload raw logs or screenshots.

### Version and environment

Include version, source commit, OS, Node.js, Copilot CLI or app version, cloud provider, and relevant session settings. Use `unknown` for unavailable facts.
