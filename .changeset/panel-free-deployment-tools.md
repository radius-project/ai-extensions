**Added:** Start, monitor, and repair deployments with `radius_deploy` and `radius_deploy_status` without opening a Canvas panel. Tools and attached panels share the same deployment, account, monitor, and repair budget.

Attempt-only repair retains the selected committed application file and environment. Monitoring and notification retries keep the session active until they settle, even when no panel has opened or the last panel closes.

Custom-file failure handoffs include the runtime bootstrap for safe sibling staging, validation and target-only publication. Delivery retries retain that same admitted file; unavailable required workflow templates refuse deployment without starting automatic model repair.
