Tighten several correctness and accessibility edges in the environment page that the unified credential and environment flow exposed. The infrastructure hand-off between the environment form and the discovery panel now records which provider it belongs to, so an Azure discovery that finishes while an AWS hand-off is outstanding can no longer consume it and render one provider's cluster and namespace into the other's fields. Cancelling the credential form while it is docked in the environment wizard now invalidates the in-flight save the same way leaving the standalone form already did, so a save that resolves after Cancel no longer advances the wizard with a profile the user walked away from. The credential-usage lookup performed before deleting a profile treats a non-OK response and an error payload as failures rather than as an empty environment list, so the delete dialog says it could not check instead of implying the profile is unused, because the handler reports its own failures as HTTP 200 with an error field. The environment confirmation dialog traps Tab and Shift+Tab between its two buttons and returns focus to whatever opened it, so a keyboard user is neither dropped into the inert page behind an aria-modal dialog nor left at the top of the document once it closes. An environment whose status is missing or unrecognized is now labelled and explained as unknown instead of being described as still being created, which was a false explanation for a status the client never received. The guidance shown for a credential profile missing its subscription, tenant, account or region now points at deleting and recreating the profile, since the edit affordance was removed. The compatibility oracle records its one non-additive marker change as an explicit intentional divergence, and the fixture loader validates that field, so the update policy's requirement is enforced rather than assumed.
