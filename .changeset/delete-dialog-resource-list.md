**Changed:** The delete confirmation now summarizes resources last reported for the selected application and environment before you type the confirmation phrase, from both the deployed graph and the deployments list. Long lists show the first several names and types, with a count of the rest. When a matching resource report is unavailable, the dialog keeps its existing warning rather than treating modeled graph nodes as deployed resources. Stopping tracking of a failed teardown is unchanged.
