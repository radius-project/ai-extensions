Classify cloud credential-verification failures and validate the Create Environment form before dispatch. A failed verify run is now inferred canvas-side from its failed step names and log into an OIDC-trust, permissions, or unreachable-cluster/cloud category, so the progress panel explains what to fix (and lists missing permissions) instead of showing one generic message. The environment form also rejects malformed environment names before the verify workflow is dispatched.
